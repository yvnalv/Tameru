# Frontend Docs

The Tameru web client design & architecture docs.

- [DESIGN_LANGUAGE.md](DESIGN_LANGUAGE.md) — the single source of truth for visual styling: colors,
  typography, spacing, radius, motion, components. **Dark-first, solid green accent, no gradients.**
- [FRONTEND_ARCHITECTURE.md](FRONTEND_ARCHITECTURE.md) — stack, folder structure, theming, API/auth,
  i18n, conventions.
- [BRAND.md](BRAND.md) — placeholder identity (mark, wordmark, usage).

Reference: the product owner's UI reference is a **dark fintech mobile app with a solid green
accent** (rounded cards, avatar chips, segmented category spend bar, dark text on green primary
buttons). Tameru adopts that language for both a mobile-first layout and the desktop web app.
